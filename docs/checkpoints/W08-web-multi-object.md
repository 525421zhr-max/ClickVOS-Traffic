## 实际完成

- Web 支持新建、删除和切换目标，单任务最多 20 个对象。
- 每个对象独立保存对象 ID、类别、正点和负点；每个对象至少需要一个正点。
- 一次 SAM2 会话同时传播全部目标，不为每个对象重复加载模型。
- 使用六种循环颜色区分对象，首帧点击和传播预览均显示对象颜色。
- 每个对象保存到独立目录：`masks/object_NNN/`。
- `result.json` 按对象记录提示点、颜色、类别、逐帧像素、连通区域、异常和保护帧。
- 中间帧修正增加目标选择，修正选定对象时其他对象仍保留在会话和合成预览中。
- 保留对象 1 的旧结果字段和扁平掩码路径，已有 W06、W07 回归脚本继续兼容。

## 接受结论与限制

工程门通过：用户可以在网页首帧为多个物体分别添加正负点，一次完成多对象传播，并得到逐对象掩码和合成预览。

当前只在同一公开视频的两个车辆上完成真实 Web 路径验证。没有逐帧真值，因此不计算 IoU、J、F，也不宣称多目标精度优于单目标。不同对象掩码发生重叠时，目前按对象 ID 顺序绘制颜色，尚未提供重叠冲突提示。
