- 日期：2026-09-21

## 做了什么

- 历史任务增加清理范围预览，显示视频名、帧数、文件数和占用空间。
- 用户必须完整输入任务编号，才能把任务移入 `outputs/task_trash`。
- 清理前再次核对文件数量、字节数和最新修改时间；预览后内容变化会拒绝操作。
- 当前活动推理任务不能清理。
- 清理采用同文件系统移动，不立即永久删除，并写入 `.archive.json` 便于人工恢复。
- Docker 挂载调整为整个 `outputs` 目录，保证任务与回收区位于同一持久卷。

## 遇到的问题

- 第一次 Web 启动验证命令的 shell 变量被调用层提前处理，未得到有效结果；改用独立前台会话后验证成功，没有修改项目数据。
- 若容器分别挂载任务目录和回收目录，原子移动可能跨文件系统失败。因此 Compose 改为挂载整个 `outputs`。
- 移入回收区不会释放磁盘空间；永久清理仍需单独设计保留期和审计日志。
