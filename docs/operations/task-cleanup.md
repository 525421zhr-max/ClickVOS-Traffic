# 历史任务清理与恢复

Web 中的“清理所选任务”采用可恢复移动，不会立即永久删除文件。

## 安全流程

1. 在历史任务列表选择任务。
2. 点击“预览清理范围”，核对视频名、帧数、文件数和占用空间。
3. 在确认框中完整输入任务编号。
4. 点击“移入可恢复回收区”。

系统会再次检查任务内容是否与预览一致，并拒绝清理当前活动推理任务。成功后，任务从 `outputs/tasks` 原子移动到 `outputs/task_trash`，同时写入 `.archive.json`。这一操作不会释放磁盘空间。

## 手动恢复

关闭 ClickVOS 后，确认原任务编号未被新任务占用，再把对应目录移回：

```bash
mv outputs/task_trash/<任务编号-归档时间> outputs/tasks/<任务编号>
rm outputs/tasks/<任务编号>/.archive.json
```

执行前必须核对源目录中的 `.archive.json` 和目标路径。当前版本没有 Web 恢复按钮，也不会自动永久删除回收区内容。

## 后续自动过期清理

未来的永久清理将独立实现，至少需要保留期、清单预览、二次确认和操作日志。在这些条件完成前，不自动删除回收区数据。
