# ClickVOS Traffic 项目章程

## 项目定位

ClickVOS Traffic 是一个基于 SAM2 的交通视频交互式分割与半自动标注工具。项目的第一目标是把软件做出来、让其他人能够使用；在此基础上，再研究提示方式、传播失败和人工修正。

目标用户包括交通视频研究人员、计算机视觉学习者和需要制作像素级视频标注的小型团队。系统不承担自动驾驶决策、事故预测或执法判断。

## 要解决的问题

1. 逐帧绘制车辆、行人和非机动车掩码成本高。
2. SAM2 官方研究代码安装和操作门槛较高。
3. 遮挡、小目标、快速运动、相似目标和镜头运动可能造成传播漂移。
4. 普通用户难以判断应该在哪一帧补充提示。
5. 长视频、多目标和云端并发受到显存、处理时间及文件安全约束。

## 计划中的完整流程

1. 上传并校验交通 MP4。
2. 抽帧并显示可交互画面。
3. 创建目标，选择类别，添加正点和负点。
4. 预览当前帧掩码并传播视频。
5. 标记疑似漂移帧，引导用户复核和追加提示。
6. 保存对象 ID、类别、提示历史和逐帧掩码。
7. 导出绿色叠加视频、原始 PNG 掩码和至少一种标准标注格式。
8. 自动清理过期临时文件（尚未实现）。

## 研究问题

- 单正点、正负点、框提示和中间帧修正的点击成本与效果差异。
- 面积突变、质心跳跃、相邻帧 IoU、目标消失和掩码重叠能否提示传播失败。
- SAM2 模型规模、输入分辨率和 offload 策略对速度、显存及质量的影响。
- 交互式工具相对逐帧手工标注能节省多少时间和操作。

任何后处理或失败检测策略都先作为假设，通过固定数据和基线对照后再决定是否保留。

## 数据边界

- 禁止使用未经明确授权的个人照片、人像、私人视频及其派生内容。
- 优先选择许可证清晰的公开交通数据集，并记录数据版本、来源链接、许可证和允许的使用方式。
- 数据集原文件、模型权重和运行产物默认不提交 Git。
- 用户试用只收集任务数据和匿名反馈，不收集与研究无关的个人信息。

## 交付成果

- ClickVOS Traffic 可运行软件及可复现源码。
- 本地 GPU 使用方式和 Docker/云 GPU 部署方案。
- 软件著作权一项，具体材料按申报时最新要求准备。
- 公开交通视频实验、性能报告和失败案例集。
- 十名用户的匿名试用报告，每人完成统一任务。
- 用户手册、部署文档、结题报告、演示视频和答辩 PPT。

## 成功标准

软件层面要求从上传到导出形成闭环，并能处理中间帧修正、多目标状态、异常输入和临时文件清理。研究层面要求所有指标来自真实运行，能复现模型、数据、提示和配置；没有真值时不报告精度。结题层面至少完成一项软件著作权及学校要求的材料。

申报书中的 200MB、60 秒、1080p、8 FPS、300 帧不超过 50 秒、平均点击不超过 3 次和满意度不低于 4.2 分均暂列为待验证目标，不视为已达成事实。

## 项目约束

- 当前由一名学生承担主要开发和实验，因此优先保证闭环、证据与可维护性。
- 先使用 Gradio 完成原型，不提前引入复杂微服务和账号系统。
- 云端部署在本地流程稳定后进行，并加入上传限制、任务隔离、队列和自动清理。
- 任何结论不得引用无法找回的旧代码、旧数据或未复现的申报材料描述。
